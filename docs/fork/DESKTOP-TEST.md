## 回退方式

如需卸载，通过同一个桌面端 CLI 执行 `plugin --profile desktop remove dsh-plugin-wallpaper-engine`，然后正常退出并重启桌面端。不要仅删包目录而留下 bundle 引用。若后续还安装了其他插件，不要直接整份覆盖旧 profile 备份；先比较差异。壁纸配置的恢复也应在桌面端退出后进行，防止旧页面回写。
