# 默认壁纸与毛玻璃迷你播放器

2026-10-02，在用户确认“每次启动使用默认壁纸”和“可收起的迷你播放器”后更新。

## 使用方式

入口：**设置 → 壁纸引擎 → 壁纸库**。

- **设置为默认壁纸**：将当前壁纸设为默认。之后每次插件重新启动或页面重新加载，优先应用这张壁纸，而不是上次播放的另一张。
- **取消默认壁纸**：仅清除默认项，不清除正在播放的壁纸。
- **开启悬浮窗 / 关闭悬浮窗**：控制播放器是否显示。系统页原有开关仍与它共用 `fabEnabled`，不会形成两份设置。

旧 `defaultId` 沿用，不需要重新建立数据文件；但它的含义已由“上次壁纸失效时兜底”改为“每次启动优先使用”。目标不存在、被隐藏、分级不允许或不可播放时，不强制使用它。启动过程中的主动选择/清除优先，普通库存刷新不会把用户重新拉回默认壁纸。

## 悬浮窗交互

- 收起态：52px 玻璃按钮，显示播放状态指示点。
- 展开态：封面、标题、真实播放状态、上一张/播放或暂停/下一张、从头播放，以及内嵌壁纸列表。
- **收起**只关闭面板，保留入口；**关闭**关闭整个悬浮控件，不停止壁纸播放。
- 列表不再嵌套完整 QuickPanel，不重复显示播放器、设置页签和轮播编辑器。仍使用现有库存、来源筛选、媒体准备和选择链。
- 首次显示至多 24 张，按“显示更多壁纸”每次追加 24 张，缩略图延迟加载。避免大图库一次挂载全部卡片。
- 拖动超过 5px 才进入拖动态；拖动时收起面板，结束后靠右并保存相对高度。四角选择继续可用。
- 面板根据停靠位置向上/下展开，最大高度限定为对应方向的剩余空间。
- Esc、外部点击和失焦收起面板；输入区编辑、组合输入和按键重复不触发播放快捷键。
- 所有图标有可访问名称，控件具备焦点轮廓与展开状态；没有媒体时播放/重播禁用。

## 视觉实现

不引入外部字体、图标 CDN 或额外播放器依赖。使用 SVG 线性图标、圆角、细边缘高光、柔和阴影、半透明分层材质及 `backdrop-filter: blur(28px) saturate(170%)`。

明暗模式跟随宿主主题标记，不以操作系统偏好覆盖用户在应用里的主题。浏览器不支持背景模糊，或要求减少透明度/增强对比时回退为实色；要求减少动态效果时关闭进场及按压动画。

这是一套借鉴 Apple 轻量材质与信息层次的设计，不是 Apple 官方组件。
