# 基于干净上游的七项功能重构

日期：2026-10-02。基线：`elysia395/dsh-wallpaper-engine@d9988b3e1fa0c47d1032c67303e972ef47d5eb1c`（1.2.0）。

这是新克隆上的源码重构，不是旧 fork 的冲突合并。分支：`refactor/miao-clean-upstream`。
**取消第 8 项“自定义 WSL 发现与库存响应优化”**；上游已有的平台支持、缓存和扫描行为保留，不做无关删除。

## 功能与入口

| 功能 | 新实现与使用方式 |
|---|---|
| 上传上限 | 环境变量 `DSH_WE_UPLOAD_MAX_MB`，单位 MiB；默认保持上游 512，接受十进制整数 1–8192，其他值回落默认。变量在插件宿主加载时读取。超限响应说明真实上限；保留流式写入、背压和临时文件清理。设置环境变量和重载由使用者自行安排，本次没有修改运行环境。 |
| 来源筛选 | 壁纸库的“壁纸来源”：全部 / WE 壁纸库 / 本地媒体。筛选影响浏览、计数及快捷列表，不因切来源而清除当前壁纸或重定义轮播候选。WE 库包含上游发现的 WE 项目，不仅限于 Workshop。 |
| 本地媒体识别 | 将 MP4/JPG/JPEG/PNG 放到插件选定的自定义存储目录的**直接子级**，在界面刷新库存。无需改成 `up-*` 名称，不复制、不移动原文件。ID 包含完整文件名（包括扩展名）的 SHA-256，Windows 大小写归一；同名不同扩展名不再撞 ID。复用上游媒体和异步视频预览路由，没有新增 `/thumb`。 |
| 启动兜底壁纸 | 壁纸库当前壁纸区“设为启动兜底”。仅首次成功读入库存时、上次选择无效或为空时尝试；有效的上次选择优先。兜底也服从可播放、内容分级和隐藏条件。启动期间用户主动选择或清除会取消自动兜底，普通刷新不重新强制应用。 |
| 视频播放列表 | 在轮播列表编辑器勾选“仅视频列表：播完再切换”，选择视频并保存。支持顺序、随机、单曲循环；非视频不会加入保存后的列表。允许单视频列表，非循环模式按视频结束事件切换，不按分钟截断；复用上游候选准备和切换链。壁纸库提供上一张、下一张、从头播放；随机历史只保留本会话最近 64 项。普通轮播保持原有计时行为。 |
| 可选悬浮球 | 系统页开启“悬浮播放控制”，**新设置默认关闭**，不替代或删除上游吉祥物。黑胶球点开标题和播放控件，列表复用上游 QuickPanel。支持四角锚点、拖动后右侧吸附及高度记忆；选角会清掉拖动高度。开启时 Ctrl+Alt+左右方向键切换，Ctrl+Alt+空格播放/暂停；输入控件、编辑区域和输入法组合事件不响应快捷键。Esc、外部点击、窗口失焦收起；禁用/卸载清理监听。 |
| 输入区折叠 | 使用宿主 `sidebar.footer.action` 座位注册按钮，仅接管显式 `[data-composer-seat]` 容器。没有该座位就不注入；没有容器时按钮禁用。不再靠“猜 textarea 父节点”探测。节点替换时还原旧节点、接管新节点；展开/卸载还原原始 display 值及 important 优先级。折叠是会话状态，不落盘。 |

## 旧设置与数据边界

- `sourceFilter`、`defaultId`、`fabEnabled`、`fabPosition`、`fabSnapY` 和视频组字段都经过同一个 `lib/settings-schema.js`；客户端和宿主不再各维护一份白名单。
- `fabSnapY` 接受有限数值并钳制至 0–1；缺新字段时识别旧 `fabPoint.y`。显式 `fabSnapY: null` 表示恢复角落定位，不被旧字段覆盖。
- 旧 `file-*` 文件名主体 ID：只在别名唯一时迁移当前选择、默认选择、隐藏引用和播放列表成员。冲突时不猜；旧元数据也仅在别名唯一时读取。
- 本地媒体缺少内容分级时按 Everyone 处理；明确的限制级分级不会被覆盖。
- 普通 drop-in 文件拒绝符号链接、硬链接、路径片段、隐藏名和不支持的扩展名；不递归搜个人目录。原有 WE 项目目录导入逻辑保留。
- `local-*` 文件不进入可删除上传管理，`/remove` 拒绝这类 ID；用户可以隐藏它们。`up-*` 是上游保留的托管上传命名空间，不要把个人文件伪装成这个前缀。
- 直接重命名文件会产生新 ID；不会仅凭文件内容猜测改名关系。选择存储目录的原有迁移开关也未改写，请按其提示使用。

## 结构

- `lib/local-media.js`：上传上限解析、drop-in 文件描述符。
- `lib/index.js`、`lib/routes/upload.js`：接入原扫描和上传链。
- `src/picker-model.js`：来源筛选、无歧义别名迁移、启动兜底纯函数。
- `src/video-playlist.js`：视频组、播放结束处理和有界导航历史。
- `src/fork-controls.js`：悬浮球与可逆输入区适配器。
- `src/client.js`、`src/media-prep.js`：仍是上游状态和媒体生命周期入口，没有创建第二套播放器。
- `lib/client.js`：由 `npm run build` 生成，不能手改。

## 验证与限制

新增三组 Node 测试，纳入现有 `npm run verify:all` 链：

- `test/fork-local-media.test.mjs`：上限边界、稳定 ID、来源筛选、分级、别名及启动兜底。
- `test/fork-controls.test.mjs`：schema 往返、视频结束事件/历史、单视频/循环、折叠恢复、FAB 快捷键与监听清理。
- `test/fork-host-media.test.mjs`：真实文件系统中的生产扫描器/删除解析器、隔离 HTTP 服务器上的真实流式上传路由（1 MiB 上限、413、正常上传、临时文件清理、拒删个人文件）。不调用个人 Steam 发现，不加载运行中的 Desktop 配置。

上游普通/批量库视图快照只新增来源下拉框对应的一枚 class 令牌，保留原负对照；schema golden 只补新增默认字段；类型契约新增 source / legacyId；路由索引用上游生成器刷新，不绕过检查。

**通过自动检查不等于全部真实场景验收。** 用户后续授权了本机 profile 安装与临时回环调试，已完成 DSH NEXT 上的短 MP4 实播、结束切换、单曲循环、来源筛选、悬浮球交互/拖动及输入区折叠测试；拖动后列表越界问题已修复并回归。详见 [DESKTOP-TEST.md](DESKTOP-TEST.md)。仍需检查长视频、Edge、转码后的视频、不同缩放/小窗口及会话切换时输入区节点重建。宿主没有标准座位/容器时折叠功能按设计降级，而非侵入式猜测 DOM。

上游完整验证链有明示覆盖缺口：媒体桥二进制未 provision 时，其端到端段通过既有 `--allow-skip` 跳过；Windows 不覆盖 POSIX 专属用例。不能将它们记录为“已实测通过”。
